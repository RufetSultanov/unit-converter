# Unit Converter

Учебный проект по дисциплине «Инфраструктура и администрирование».

Приложение на FastAPI переводит температуру из градусов Цельсия в Фаренгейты, километры в мили и килограммы в фунты. Пользоваться API можно через `/docs` или curl.

## Установка

Нужен Python 3.12. Склонируйте репозиторий и выполните команды в папке проекта:

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r requirements-dev.txt

## Настройки и запуск

Название и автор задаются через переменные окружения:

export APP_NAME="Unit Converter"
export APP_AUTHOR="Rufet Sultanov"

Без этих переменных используются значения `Unit Converter` и `Rufet Sultanov`. В `.env.example` приведён пример настроек, автоматически этот файл не загружается.

Обычный запуск:

python -m uvicorn app_final:app --host 127.0.0.1 --port 8000

Для разработки можно добавить `--reload`. После изменения переменных окружения сервер нужно перезапустить.

Документация: http://127.0.0.1:8000/docs

Остановка сервера: Ctrl+C.

## Маршруты

| Адрес | Что делает |
|---|---|
| `/` | Описание приложения и автор |
| `/health` | Возвращает `{"status":"ok"}` |
| `/version` | Возвращает версию приложения |
| `/convert/temperature?celsius=20` | Переводит °C в °F |
| `/convert/distance?kilometers=10` | Переводит километры в мили |
| `/convert/weight?kilograms=5` | Переводит килограммы в фунты |

Результаты округляются до четырёх знаков после запятой.

Минимальная температура — −273.15 °C. Масса и расстояние не могут быть отрицательными. Верхняя граница для всех параметров — 10¹². Неверные или отсутствующие параметры возвращают ошибку 422.

## Тесты и GitHub Actions

Запуск тестов:

python -m pytest -v

Проверяются маршруты, расчёты, ошибки параметров, настройки и логи. Всего 29 проверок.

GitHub Actions запускает тесты при push и pull request. После успешной проверки создаётся артефакт `unit-converter` с приложением, зависимостями, README и `.env.example`. Скачать его можно на странице запуска во вкладке Actions. Срок хранения — 7 дней.

Для запуска артефакта достаточно создать окружение, установить `requirements.txt` и запустить Uvicorn. Тесты находятся в полном репозитории.

## Логи и диагностика

Логи видны в терминале запуска: старт и остановка приложения, запросы и результаты преобразований.

- `No module named ...` — проверить активацию `.venv` и установку зависимостей.
- `Could not import module app_final` — перейти в папку с `app_final.py`.
- `Address already in use` — остановить предыдущий сервер или выбрать `--port 8001`.
- `Connection refused` — проверить, запущен ли сервер и правильно ли указан порт.
- Ошибка 422 — проверить параметры запроса.
